# Дорожные препятствия и бонусы (вид сверху)

Общие спрайты для любых гоночных игр Тагшим. Нарисованы в GPT для «Улицы» (режим «Угнать крузака»), прозрачный фон.

| файл | что | роль |
|---|---|---|
| barrier.webp | дорожный ремонт, полосатый барьер | препятствие |
| manhole.webp | открытый люк | яма — трясёт/прокол |
| oil.webp | лужа масла | занос |
| pit.webp | яма в асфальте | тормозит |
| tree.webp | упавшее дерево (горизонтально) | стена поперёк |
| cart.webp | телега с лошадью (носом вверх) | медленная помеха |
| tractor.webp | трактор «Беларусь» (носом вниз) | встречная помеха |
| gate.webp | шлагбаум | перекрывает полосу |
| crates.webp | куча ящиков | ломаемое |
| barrel.webp | бочка | ломаемое / катится |
| fuel.webp | канистра (светится) | бонус: топливо |
| wrench.webp | гаечный ключ (светится) | бонус: починка |

Подключение из игры: `../shared/road/<файл>.webp`
